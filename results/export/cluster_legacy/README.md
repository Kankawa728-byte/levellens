# Earlier cluster CPU measurements

These reports were produced on the compute cluster and are retained for provenance. They are outside `results/export/*.json`, which `scripts/efficiency.py` reads for R7. R7 requires latency measured on a member's laptop CPU. The final DistilBERT checkpoints rechecked on Jikai's laptop are in the parent folder.

The smoke checkpoint and the earlier RACE++ cross-entropy checkpoint were not included in the checkpoint archive supplied for the laptop recheck. Their cluster timing must not be presented as laptop evidence.
