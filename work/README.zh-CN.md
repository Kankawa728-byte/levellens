# 六份工作

English: [README.md](README.md)

项目分成大小相同的六份。这一页列出逐项的小时数，每个人都可以核对分得是否公平。

- **Tier 1** 是必须完成的部分。每一份都有 24 小时。
- **Tier 2** 原本是 Tier 1 按时完成后再加的部分。每一份原有 4 小时。组长在 11 月 12 日（周四）已经取消 Tier 2。
- **11 月 12 日（周四）的重排。** 我们开始得晚，所以组长还砍掉了一些 Tier 1 的任务，并把另一些缩小。每份工作的页面都标出了已砍掉的任务，[docs/schedule.zh-CN.md](../docs/schedule.zh-CN.md) 列出全部。这一页的小时数是最初的估计，没有重新计算。
- 小时数是估算。如果你这一份比估算多出 3 小时以上，告诉组长。组长会把一项任务移给用时偏少的那一份。

所有时间都是新加坡时间。

## 每个评分项需要什么，由谁提供

| 评分项 | 证据 | 分工 |
|---|---|---|
| Requirements（要求） | 规格 R1–R8，逐条给出是否达成 | A，数字来自所有人 |
| Application and datasets（应用与数据集） | 三个训练数据集、一个外推测试集、数据集卡片 | A、B |
| Framework（框架） | 模型选择和各项改进：有序输出头、Optuna、ARC 稳定性 | E |
| Experiment design（实验设计） | 九项指标、已发表的基线、我们自己的基线 | A、B、D |
| Interpretation（解释） | 全局 SHAP、LIME、迁移、外推、人工核对 | D、F、B |
| Readability（可读性） | 一个代码包、文档字符串、主 notebook、README、审阅过的 pull request | 所有人、A |
| Efficiency（效率） | 分词结果缓存、剪枝、限定规模的数据集、效率表 | E、C |
| Reusability（可复用性） | 共用的统一格式、Predictor API、配置 | A |
| Presentation（展示） | Streamlit 应用 | F |
| Video（视频） | 六个人都讲；分镜；拼接 | 所有人、B、A |
